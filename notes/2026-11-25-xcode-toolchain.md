# Xcode для тестов Shotnix

- На Mac с macOS 26.5.1 активны Command Line Tools со Swift 6.3.3. Полный Xcode не найден. В установленных инструментах есть библиотеки поддержки XCTest, но компилятор не находит модуль XCTest для тестов пакета.
- По таблице совместимости Apple подходит Xcode 26.6. Текущая версия в Mac App Store требует macOS 26.6 или новее. Официальная страница загрузки Xcode 26.6 для Apple Silicon перенаправляет на вход в Apple Account. Установка ожидает доступа к архиву через Apple Developer.
