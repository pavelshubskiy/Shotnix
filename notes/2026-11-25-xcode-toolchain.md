# Xcode для тестов Shotnix

- На Mac с macOS 26.5.1 активны Command Line Tools со Swift 6.3.3. Полный Xcode не найден. В установленных инструментах есть библиотеки поддержки XCTest, но компилятор не находит модуль XCTest для тестов пакета.
- По таблице совместимости Apple подходит Xcode 26.6. Текущая версия в Mac App Store требует macOS 26.6 или новее. Официальная страница загрузки Xcode 26.6 для Apple Silicon перенаправляет на вход в Apple Account. Установка ожидает доступа к архиву через Apple Developer.

## После установки

- Xcode 26.6 (17F113) установлен в `~/Downloads/Xcode.app`. Сборка прошла из основного репозитория со SwiftUI-превью KeyboardShortcuts. Для запуска использовался `DEVELOPER_DIR` на уровне команды. Системный `xcode-select` указывает на Command Line Tools.
- Первая сборка тестов нашла устаревшую проверку `RecordingTargetKind.area.title` после переработки окна записи. Тест теперь сравнивает `recordingTitle` с немецким заголовком `Bereich aufzeichnen`.
- Повторный прогон прошёл без ошибок. Выполнены 20 тестов выделения, 16 тестов фокуса, 9 тестов заморозки и 1 тест локализации.

## После удаления приложения из «Загрузок»

- Xcode и архив `.xip` не найдены в «Программах», «Загрузках» и на Рабочем столе. Корзина пуста. Проверенные локальные снимки Time Machine сделаны до установки Xcode. Активным остаётся набор Command Line Tools. Для повторного запуска штатных тестов нужен Xcode, например в `/Applications/Xcode.app`.
