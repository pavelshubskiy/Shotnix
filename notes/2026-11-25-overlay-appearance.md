# Тема миниатюры скриншота

- Окно миниатюры использует текущую тему Shotnix. Светлый вариант получил белую панель, тёмные иконки и контрастную кнопку копирования. При системной теме окно наследует тему macOS.
- Открытая карточка меняет оформление сразу. Цвета рамки, кнопок, подложки картинки и полосы таймера обновляются через эффективную тему AppKit. Изображение снимка сохраняет исходные цвета.
- Проверка на одном открытом окне прошла для переключения тёмная → светлая → тёмная. Сравнили пиксели панели и тестового снимка, просмотрели обе темы. Первый пробный объект NSImage был рисуемым без CGImage для записи истории. Повторная проверка с CGImage-подложкой прошла без этой ошибки.
- SwiftPM собрал временную копию без Xcode-превью KeyboardShortcuts. Локальный форк упакован, подписан прежним сертификатом и запущен.
