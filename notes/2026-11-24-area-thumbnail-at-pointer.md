# 24 ноября 2026. Миниатюра снимка области рядом с курсором

- Обычный снимок выбранной области передаёт в окно миниатюры координаты отпускания кнопки мыши. Если область уточняли, используется положение курсора при подтверждении. Координаты сохраняются до асинхронного захвата.
- Карточка открывается в 12 пунктах от курсора, по умолчанию справа и снизу. У края она разворачивается внутрь рабочей области монитора. При перекрытии более ранняя карточка перемещается в угловую стопку. Для других режимов применяется обычная стопка.
- Проверка AppKit прошла для точного события отпускания, клика подтверждения, рабочей области дисплея и повторной карточки. Проверка положения окна учитывает округление AppKit до целых пунктов. Захват экрана через запущенный форк вручную не проверяли.
- SwiftPM разрешил зависимости. Сборка исходного пакета с Command Line Tools останавливается на трёх `#Preview` в KeyboardShortcuts. Для локальной сборки удалены только эти превью во временной копии. В ней приложение собрано, а `swift test` остановился из-за отсутствия модуля XCTest. Проверки выполнены отдельным исполняемым тестом AppKit.
- В корне проекта собрана и проверена через `codesign` отладочная `Shotnix Fork.app` для Apple Silicon. У неё отдельный идентификатор `ru.shubskiy.shotnix.fork` и отключено автообновление. Официальная сборка в `/Applications` не заменялась. Обе версии используют одну папку истории Shotnix.
